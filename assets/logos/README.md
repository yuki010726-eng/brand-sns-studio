# 브랜드 로고 파일

1단계 프로필 세팅의 「브랜드 로고」 칸이 여기를 본다.
파일을 넣으면 화면에 바로 뜨고, 없으면 안내문으로 바뀐다. **없어도 앱은 정상 동작한다.**

## 이름 규칙

파일 이름은 `data/products.js` 의 상품 `id` 와 **똑같이** 맞춘다. 확장자는 `.png` 고정이다.

| 브랜드 | 파일 |
|---|---|
| KBS N 브랜드어워즈 | `kbsn.png` |
| 포브스 브랜드어워즈 | `forbes.png` |
| KCST 대한민국 고객만족도 신뢰도 대상 | `kcst.png` |
| 중소기업 AI TV CF | `aitvcf.png` |

경로를 만드는 곳은 `lib/profile.js` 의 `awardLogoSrc()` 한 곳이다.
확장자를 바꾸고 싶으면 그 함수만 고친다.

> ⚠️ 여러 확장자를 순서대로 시도하게 만들지 말 것. 없는 파일마다 404 가 콘솔에 쌓인다.

## 어떤 파일을 넣나

프로필 이미지를 만들 때 **AI 에게 그대로 첨부하는 원본**이다. 화면에서 내려받아 쓴다.

- **정사각형 PNG, 배경 투명 권장.** 아바타가 정사각형이라 세로로 긴 로고는 여백이 크게 남는다.
- **512px 이상.** 작으면 모델이 로고 안의 글자를 뭉개서 다시 그린다.
- 파일 하나에 로고 하나만 둔다. 여백·설명·워터마크가 같이 들어가면 그것까지 따라 그린다.

## 왜 로고를 첨부하나

로고 없이 만들면 프롬프트가 심볼을 **지어낸다.** 계정이 브랜드로 안 읽힌다.
로고를 첨부하면 프롬프트가 심볼을 말하지 않고 주변 연출만 지시하므로,
그 브랜드의 실제 마크가 들어간 프로필이 나온다.

자세한 이유와 주의점은 `lib/profile.js` 의 이미지 프롬프트 절 주석에 있다.
특히 **로고 모드에서 심볼 이름이나 `no text` 를 프롬프트에 되살리지 말 것** —
전자는 로고를 밀어내고, 후자는 로고 안의 글자를 지운다.
